КІНОПОШУК — ІНСТРУКЦІЯ ЗАПУСКУ

1. Відкрийте файл script.js.
2. Знайдіть рядок:
   const API_KEY = 'ВСТАВ_СВІЙ_API_KEY';
3. Замініть ВСТАВ_СВІЙ_API_KEY на власний ключ OMDb API.
4. Відкрийте index.html через розширення Live Server у Visual Studio Code.

У проєкті є пошук фільмів, серіалів та епізодів, пагінація і перегляд детальної інформації.
Для роботи потрібне підключення до Інтернету.
